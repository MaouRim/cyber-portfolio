## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/MaouRim/cyber-portfolio.git
```

Go into the project directory:

```bash
cd cyber-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🌐 Deployment

Deploy to GitHub Pages:

```bash
npm run deploy
```
